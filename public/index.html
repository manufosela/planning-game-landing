XP Planning Workflow

From backlog to delivery, following eXtreme Programming practices. Priority auto-calculated from business value and dev effort.

Backlog → Sprint Planning → In Progress → To Validate → Done & Validated

XP Planning Game

Estimate tasks using business value and development effort. Priority is auto-calculated: (businessPoints / devPoints) x 100. No manual priority setting.

▦

Multi-View

List, Kanban, Sprint, and Gantt views. See your project the way you need it. Switch views without losing context.

⯈

MCP Server

25+ tools for AI agents. Claude, Codex, and any MCP-compatible host can manage your project programmatically.

⚡

Real-Time Collaboration

Firebase-powered real-time sync. Every change is instantly visible to all team members. No refresh needed.

⚙

Role-Based Permissions

SuperAdmin, Admin, User, Consultant roles. Fine-grained access control. Validators approve tasks, developers self-assign.

✓

WIP Limits

One task in progress per developer, enforced across all projects. Focus on finishing before starting new work.

☰

Sprint Management

Plan sprints, track velocity, manage backlogs. Year-based filtering for long-running projects. Burndown charts included.

✎

Architecture Decision Records

Track ADRs alongside your tasks. Keep architectural decisions visible, searchable, and linked to the code that implements them.

⚛

AI-Native Workflow

Designed for human + AI collaboration. Track AI usage per task, auto-assign AI agents, measure contributions. The same rules apply to humans and AI.

AI Agents in Action

Your AI agent manages tasks through the MCP server. No UI needed.

$ claude "Create a task for the login refactor"

[MCP] list_cards type=epic → Found 3 epics
[MCP] list_sprints → Using Sprint PLN-SPR-0012
[MCP] create_card type=task title="Refactor login flow"
[MCP] update_card status="In Progress" developer=BecarIA

✔ Task PLN-TSK-0245 created and assigned

MCP Server Included

25+ tools for managing projects, cards, sprints, ADRs, and plans. Any MCP-compatible AI agent can interact with your planning board.

Add the Planning Game MCP server to your AI agent configuration:

{
  "mcpServers": {
    "planning-game": {
      "command": "node",
      "args": ["/path/to/planning-game-xp/mcp/index.js"],
      "env": {
        "FIREBASE_PROJECT_ID": "your-project"
      }
    }
  }
}
