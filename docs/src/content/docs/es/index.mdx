## Por qué Planning Game XP?

Diseñado para equipos que se toman en serio el desarrollo ágil. Planning Game XP sigue las prácticas de eXtreme Programming con enforcement real, no solo sugerencias.

<CardGrid stagger>
  <Card title="Flujo XP-First" icon="rocket">
    Sprints, épicas, tareas, bugs, proposals y QA — todo con transiciones de estado estrictas, límites WIP y gates de validación.
  </Card>
  <Card title="Integración MCP" icon="puzzle">
    Servidor MCP integrado con más de 25 herramientas. Los agentes de IA pueden crear tareas, actualizar estados, gestionar sprints y rastrear el pipeline.
  </Card>
  <Card title="Colaboración en Tiempo Real" icon="laptop">
    Firebase Realtime Database potencia actualizaciones instantáneas. Múltiples miembros del equipo ven los cambios al instante.
  </Card>
  <Card title="Seguimiento de Pipeline" icon="approve-check">
    Rastrea cada card desde el commit hasta el despliegue. Badges automáticos para Committed, PR Created, Merged y Deployed.
  </Card>
  <Card title="Múltiples Vistas" icon="list-format">
    Vistas Lista, Kanban, Sprint y Gantt. Filtra por desarrollador, estado, sprint, épica o año.
  </Card>
  <Card title="Desarrollo Asistido por IA" icon="star">
    BecarIA (dev_016) gestiona tareas de forma autónoma. Planes de implementación, generación de criterios de aceptación y revisión de código automatizada.
  </Card>
